# ClaimReview Dataset

> [!IMPORTANT]
> Dataset can be downloaded from [MartinoMensio ClaimReview release snapshot `2026_06_12`](https://github.com/MartinoMensio/claimreview-data/releases/tag/2026_06_12)

This directory contains the ClaimReview dataset used in the FakeNews project. The dataset is sourced from the MartinoMensio ClaimReview release snapshot `2026_06_12`. The expected local path for the dataset is:

```bash
src/datasets/data/claimreview/2026_06_12/claim_reviews.json
```

Source is now pinned to this snapshot for reproducibility. The ClaimReview loader will fail fast if this file is missing.
